# Welcome to MyNote

MyNote keeps your notes as ordinary Markdown files while giving you a clean browser-based writing experience.

## What makes it different?

- **Your files stay portable.** Open them in MyNote, VS Code, Obsidian, or any text editor.
- **Git records every saved change.** Review the full repository history or the history of one note.
- **You decide where it runs.** Use it locally or deploy it to your own server with Docker.
- **Nothing is written while you type.** Changes reach disk and Git only when you select **Save and sync**.

## Try these features

1. Search for `Docker` from the note list.
2. Filter the list by the `Demo` or `Git` tag.
3. Open **Markdown Playground** to see rich Markdown content.
4. Select **Edit**, change a sentence, and preview it before saving.
5. Open this note's history after saving to see the new Git commit.
