# 中文功能示例

MyNote 支持中文标题、正文、标签和文件名，并可以在英文与简体中文界面之间切换。

## 可以体验的功能

- 在首页搜索“中文”或“标签”
- 点击 `中文` 标签筛选笔记
- 进入编辑模式，使用工具栏插入标题、列表、链接和代码块
- 粘贴截图或拖入图片，然后在预览区查看效果
- 点击“保存并同步”，通过 Git 记录这次修改
